## Versions Prises en Charge

Ce projet étant un portfolio professionnel statique, seule la version actuellement en ligne sur [moget.online](https://moget.online) est activement maintenue et supervisée pour les mises à jour de sécurité.

| Version | Prise en charge |
| ------- | --------------- |
| Production (Actuelle) | :white_check_mark: |
| Anciennes versions / Archives | :x: |

## Signaler une Vulnérabilité

La sécurité et la protection des données sont des priorités absolues. Si vous découvrez une faille de sécurité ou une vulnérabilité sur ce site, merci de **ne pas** ouvrir de ticket public (Issue). Signalez-la plutôt de manière confidentielle :

*   **Par Email :** Envoyez un descriptif détaillé à [volny@moget.online](mailto:volny@moget.online) .
*   **Contenu du rapport :** Pour m'aider à corriger le problème rapidement, merci d'inclure les étapes de reproduction, l'impact potentiel et, si possible, une preuve de concept (PoC).

### à quoi vous attendre ?

*   **Accusé de réception :** Je m'engage à répondre et à accuser réception de votre rapport sous **48 heures ouvrées**.
*   **Résolution :** Une fois la vulnérabilité validée, un correctif sera déployé dans les plus brefs délais selon la complexité du problème. Vous serez tenu informé de l'avancée de la résolution.

Merci pour votre contribution à la sécurité de ce site.


# Security Policy

## Supported Versions

As this project is a static professional portfolio, only the version currently deployed and live is actively monitored and supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Live Production | :white_check_mark: |
| Legacy / Archives | :x:                |

## Reporting a Vulnerability

Security and data protection are highly valued. If you track down a security vulnerability, please **do not** open a public issue. Instead, report it confidentially:

*   **By Email:** Please send a detailed report to [volny@moget.online](mailto:volny@moget.online) .
*   **Report Content:** To help me fix the issue quickly, please provide clear reproduction steps, potential impact, and a proof of concept (PoC) if applicable.

### What to expect?

*   **Acknowledgment:** I commit to acknowledging receipt of your report within **48 business hours**.
*   **Resolution:** Once validated, a fix will be developed and deployed as soon as possible. You will be kept updated throughout the process.

Thank you for helping keep this project secure.
